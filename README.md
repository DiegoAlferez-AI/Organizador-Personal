## Colaboración

Este repositorio se trabajó en parejas bajo el flujo de colaboración externa mediante
*Fork* y *Pull Request* descrito en la práctica integradora.

Flujo seguido por el colaborador:

1. **Fork** del repositorio original hacia la cuenta del colaborador.
2. **Clone** del fork en el equipo local.
3. **Reconstrucción del entorno:** `python -m venv .venv` y `pip install -r requirements.txt`
   (la carpeta `.venv/` no viaja con el repositorio).
4. **Rama de trabajo:** `git switch -c mejora-documentacion`, para no modificar `main`
   directamente.
5. **Aportación:** se agregó `docs/recomendaciones.md` y la presente sección, y se creó un
   commit con el mensaje `Agrega recomendaciones al proyecto`.
6. **Push** de la rama al fork: `git push -u origin mejora-documentacion`.
7. **Pull Request** desde `mejora-documentacion` del fork hacia `main` del repositorio original.

### Aportación del colaborador

Se agregó el documento `docs/recomendaciones.md` con seis recomendaciones de mejora
detectadas durante la revisión, entre ellas retirar la carpeta `.venv/` del control de
versiones, crear el archivo `.gitignore` en la raíz y completar los archivos de
documentación que se encuentran vacíos.
